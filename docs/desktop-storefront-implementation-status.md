# สถานะการทำหน้าร้าน SOULMATE สำหรับจอคอมพิวเตอร์

การลงมือทำ **ครบทั้ง 14 tickets (01–14)** แล้ว ครอบคลุมเฉพาะฝั่งผู้ใช้ตามสเปก ตั๋วยังคงสถานะ `ready-for-human` เพราะ tracker ที่เลือกใช้มีสถานะมาตรฐานและไม่มีสถานะ `done`; `ready-for-human` ใช้บอกว่ายังมีขั้นตรวจรับโดยคน ส่วนแต่ละตั๋วระบุ `Implementation: complete` ไว้ชัดเจนแล้ว

## ตรวจแล้ว

- `npm run lint` (`tsc --noEmit`) ผ่าน
- เปิดหน้า Home ในเบราว์เซอร์จริงแล้วตรวจการจัดวางจอกว้างและค้นหาในเนื้อหาหน้าแรก
- ตรวจว่าปุ่มตะกร้าอยู่ก่อนบัญชี และทั้งคู่ชิดขวาของแถบเมนู
- เลื่อนจากกลาง iframe ลงได้ และแถบเมนู sticky ยังค้างด้านบน
- ตรวจเงาแถบเมนูและกรอบ/เงาการ์ดสินค้า

## ยังรอตรวจรับ

- ตรวจการทำงานปลายทางสินค้า → ตะกร้า → checkout / สั่งซื้อจริง รวมถึง auth และบัญชี
- ตรวจจอมือถือ/จอแคบและ keyboard-only ให้ครบทุกเส้นทาง
- Production build ยังรันไม่ได้ในสภาพแวดล้อมนี้: Tailwind Oxide Windows native dependency โหลดไม่ได้ (`stream did not contain valid UTF-8`) และ Vite พบ `spawn EPERM`

ช่อง acceptance ในแต่ละตั๋วจึงยังไม่ถูกติ๊กเป็นการรับรอง QA ครบถ้วน แต่ implementation ในขอบเขตตั๋วทั้งหมดทำแล้ว
