# ร่างแบ่งงาน: หน้าร้าน SOULMATE บนจอคอมพิวเตอร์

อ้างอิง [สเปก](./desktop-storefront-spec.md) และ [site map](./soulmate-website-sitemap.png) เฉพาะฝั่งผู้ใช้ รายการ 14 ข้อนี้ได้รับการยืนยันแล้วและเผยแพร่เป็นไฟล์ตั๋วแยกใน [local Markdown tracker](../.scratch/desktop-storefront/issues/)

**สถานะปัจจุบัน:** ลงมือทำครบทั้ง 14 tickets แล้ว ตั๋วอยู่สถานะ `ready-for-human` เพื่อรอตรวจรับในเบราว์เซอร์ ดูผลและรายการ QA ที่ยังค้างใน [รายงานสถานะ implementation](./desktop-storefront-implementation-status.md)

ทุกตั๋วเป็นงานแนวตั้ง: เปิดหน้าจริงได้ มีเนื้อหาหรือสถานะตามจริง ใช้ข้อมูล/บริการเดิมเมื่อมี ตรวจการทำงานที่ความกว้างคอมพิวเตอร์และมือถือ และรักษาทางเดินคีย์บอร์ด ไม่มีตั๋วสำหรับ Admin หรือสร้างระบบ RAG ในชุดนี้

1. **โครงหน้าร้านจอกว้างและหน้าแรกที่นำทางได้**  
   **Blocked by:** ไม่มี  
   **What it delivers:** ผู้ใช้เปิดหน้าแรกบนจอคอมพิวเตอร์แล้วเห็นโลโก้ เมนู ค้นหา บัญชี ตะกร้าพร้อมจำนวนสินค้า ส่วนท้าย และทางเข้าสินค้าที่ยังทำงานได้ โดยมือถือคงรูปแบบเดิม หน้าแรกนี้เป็นตัวอย่างใช้งานจริงของโครงร่วมสำหรับหน้าถัดไป

2. **พื้นที่ผู้ช่วยแนะนำสินค้าบนหน้าแรก**  
   **Blocked by:** 01  
   **What it delivers:** ผู้ใช้เห็นพื้นที่ product guidance assistant ในส่วนแรกของหน้าแรก โดยยังเห็นโปรโมชันและทางเข้าสินค้า พื้นที่แสดงสถานะยังไม่เปิดใช้ตามจริงและมีขนาด/โครงพร้อมรองรับคำถาม คำตอบ และสินค้าแนะนำในงาน RAG ภายหลัง

3. **รายการสินค้า ค้นหา หมวดหมู่ และตัวกรองบนจอกว้าง**  
   **Blocked by:** 01  
   **What it delivers:** ผู้ใช้เข้าสู่รายการสินค้า ค้นหาและกรองสินค้าจริงได้ ดูผลลัพธ์แบบกริดจอกว้าง และแยกสถานะโหลด ว่าง และผิดพลาดได้ โดยไม่แสดงข้อมูลสินค้าปลอม

4. **รายละเอียดสินค้าและการเลือกซื้อบนจอกว้าง**  
   **Blocked by:** 01  
   **What it delivers:** ผู้ใช้เปิดลิงก์สินค้าที่มีอยู่ ดูภาพ รายละเอียด ตัวเลือก ราคาและสต็อก แล้วเพิ่มลงตะกร้าได้บนหน้าจอกว้าง พร้อมกำหนดการเปลี่ยนทางจาก path รายละเอียดใน site map ไปยัง path ที่แอปใช้อยู่

5. **ตะกร้าและคูปองบนจอกว้าง**  
   **Blocked by:** 01  
   **What it delivers:** ผู้ใช้เห็นรายการสินค้า ปรับจำนวน ลบสินค้า ใช้คูปองที่ระบบรองรับ ดูสรุปยอด และไปชำระเงินได้ โดยจำนวนตะกร้าในเมนูตรงกับข้อมูลจริง

6. **ชำระเงินและหน้าสั่งซื้อสำเร็จบนจอกว้าง**  
   **Blocked by:** 01  
   **What it delivers:** ผู้ใช้ทำขั้นตอนกรอกที่อยู่ เลือกการส่งและวิธีชำระเงินที่ระบบรองรับ ตรวจสรุปยอด และเห็นผลสำเร็จตามพฤติกรรมเดิม โดยแบบฟอร์มกับสรุปคำสั่งซื้อใช้พื้นที่จอกว้างได้ดี

7. **เข้าสู่ระบบและสมัครสมาชิกบนจอกว้าง**  
   **Blocked by:** 01  
   **What it delivers:** ผู้ใช้เข้าและสลับระหว่างสองหน้าได้ กรอกข้อมูล รับข้อผิดพลาดที่อ่านเข้าใจ และกลับไปยังปลายทางที่ตั้งใจเปิดตามระบบเดิม

8. **ภาพรวมบัญชีและโปรไฟล์บนจอกว้าง**  
   **Blocked by:** 01  
   **What it delivers:** ลูกค้าที่เข้าสู่ระบบเห็นเมนูบัญชีกับข้อมูลของตน แก้ไขข้อมูลที่ระบบรองรับ และออกจากระบบได้ พร้อมจัดการความต่างระหว่าง path โปรไฟล์ใน site map กับแอป

9. **รายการคำสั่งซื้อและรายละเอียดบนจอกว้าง**  
   **Blocked by:** 08  
   **What it delivers:** ลูกค้าที่เข้าสู่ระบบดูประวัติ รายละเอียด และสถานะคำสั่งซื้อของตนได้ในรูปแบบที่อ่านง่ายบนจอกว้าง พร้อมจัดการความต่างของ path คำสั่งซื้อ

10. **เกี่ยวกับเราและติดต่อเรา**  
    **Blocked by:** 01  
    **What it delivers:** ผู้ใช้เปิดสองกลุ่มหน้าจากเมนูได้ เห็นส่วนเรื่องราว/วิสัยทัศน์/ทีมงานและช่องทางติดต่อ/FAQ ด้วยข้อมูล SOULMATE ที่มีจริง ส่วนแบบฟอร์มหรือข้อมูลที่ยังไม่มีบริการต้องแสดงสถานะตามจริง

11. **รายการบทความและหน้าอ่านบทความ**  
    **Blocked by:** 01  
    **What it delivers:** ผู้ใช้เข้าเส้นทางบทความ ดูรายการ หมวดหมู่ และหน้าอ่านบทความได้เมื่อมีเนื้อหาที่ตรวจสอบแล้ว หากยังไม่มีข้อมูล ระบบแสดงสถานะว่างที่ชัดเจนโดยไม่แต่งบทความหรือ health claim

12. **ชุมชน กิจกรรม และกฎชุมชน**  
    **Blocked by:** 01  
    **What it delivers:** ผู้ใช้เข้าเส้นทางชุมชนและเห็นพื้นที่กระทู้ ประสบการณ์ กิจกรรม และกฎชุมชนในโครงจอกว้าง ส่วนการโพสต์หรือเข้าร่วมแสดงสถานะตามบริการที่มีจริง ไม่ทำปุ่มที่กดแล้วไม่มีผล

13. **ที่อยู่และรายการที่ชื่นชอบจากบัญชี**  
    **Blocked by:** 08  
    **What it delivers:** ลูกค้าที่เข้าสู่ระบบเปิดหน้าที่อยู่และรายการที่ชื่นชอบจากเมนูบัญชีได้ หากบริการยังไม่มี ให้เห็นสถานะที่อธิบายได้ชัดและไม่มีข้อมูลสมมติ

14. **นโยบาย ข้อกำหนด และหน้าสถานะพิเศษ**  
    **Blocked by:** 01  
    **What it delivers:** ผู้ใช้ไปหน้านโยบาย/ข้อกำหนดจากส่วนท้ายและกลับออกได้ รวมถึงเห็นหน้า 404, coming soon และ maintenance ที่สื่อสถานะจริง ไม่มีข้อความนโยบายที่แต่งขึ้นแทนเอกสารของร้าน

หน้าที่ site map มีแต่บริการยังไม่พร้อมอยู่ในขอบเขตของตั๋วชุดนี้ในรูปหน้าแสดงสถานะตามจริง ตามร่างที่ได้รับการยืนยัน
