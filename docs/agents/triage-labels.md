# Triage labels

The tracker uses the five standard skill roles as its status strings.

| Role | Status in this tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Awaiting maintainer evaluation |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready to start |
| `ready-for-human` | `ready-for-human` | Requires a human action or decision |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill asks for a triage role, write the matching string in the issue's `Status:` line.
