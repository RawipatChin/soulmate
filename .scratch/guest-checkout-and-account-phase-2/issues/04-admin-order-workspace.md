# 04: Admin เห็นคำสั่งซื้อจาก guest และบัญชี

**What to build:** ผู้ดูแลระบบเปิดรายการและรายละเอียด Order จากแหล่งข้อมูลเดียวกันได้ รวมทั้งคำสั่งซื้อ guest และลูกค้าที่เข้าสู่ระบบ พร้อมยอดและสถานะที่ถูกบันทึกจริง

**Blocked by:** #01 Guest บันทึกคำสั่งซื้อรอชำระในระบบทดสอบ.

**Status:** ready-for-agent

- [ ] Admin และ Super Admin เห็นรายการ Order จาก guest และบัญชี พร้อมรายละเอียดและสถานะจริง
- [ ] ตัวเลขคำสั่งซื้อใน dashboard ใช้ข้อมูล Order เดียวกับหน้ารายการ ไม่ใช้ตัวเลขตัวอย่าง
- [ ] Customer, guest และบัญชีที่ถูกระงับอ่านรายการ Order หลังบ้านไม่ได้ทั้งทางหน้าเว็บและฐานข้อมูล
- [ ] การจัดการสถานะทำได้เฉพาะสิทธิ์ที่กำหนด และไม่เปลี่ยนสถานะชำระเงินเป็นสำเร็จโดยอาศัยปุ่มในหน้าเว็บอย่างเดียว
