# 05: ป๊อปอัปอีเมล guest แบบสาธิต

**What to build:** หลังบันทึก Order ของ guest ระบบแสดงป๊อปอัปสาธิตที่อ้างอิงอีเมลติดต่อและเลขคำสั่งซื้อจริง โดยบอกตรง ๆ ว่ายังไม่ได้ส่งอีเมล

**Blocked by:** #01 Guest บันทึกคำสั่งซื้อรอชำระในระบบทดสอบ.

**Status:** ready-for-agent

- [ ] ป๊อปอัปแสดงหลังบันทึก Order สำเร็จเท่านั้น และใช้เลขคำสั่งซื้อกับอีเมลจาก Order ที่บันทึกจริง
- [ ] ข้อความระบุชัดว่าเป็นการสาธิต ยังไม่มีอีเมลส่งออก และการชำระเงินยังไม่สำเร็จถ้าสถานะเป็น `pending_payment`
- [ ] ปิดป๊อปอัปแล้วผู้ซื้อยังเห็นสถานะ Order ใน session ที่มีสิทธิ์เข้าถึง
- [ ] อีเมลหรือเลขคำสั่งซื้อเพียงอย่างเดียวไม่เปิดดู Order จากเครื่องอื่น และไม่มีการผูก Order เข้าบัญชีอัตโนมัติ
