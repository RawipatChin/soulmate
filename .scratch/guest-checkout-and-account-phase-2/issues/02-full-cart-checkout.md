# 02: Checkout เต็มตะกร้าและยอดที่ตรวจสอบได้

**What to build:** ผู้ซื้อส่งตะกร้าหลายรายการพร้อมตัวเลือกสินค้า ที่อยู่ และวิธีจัดส่งผ่าน checkout เดียวกัน แล้วเห็นยอดที่คำนวณจากข้อมูลร้านก่อนยืนยัน Order ที่รอชำระ

**Blocked by:** #01 Guest บันทึกคำสั่งซื้อรอชำระในระบบทดสอบ.

**Status:** ready-for-agent

ค่าจัดส่งช่วงทดลองคิด 30 บาทต่อคำสั่งซื้อ ไม่คูณจำนวนรายการสินค้า

- [ ] ตะกร้าหลายรายการและตัวเลือกสินค้าถูกแปลงเป็น Order เดียว โดยเก็บราคาแต่ละรายการ ณ เวลายืนยัน
- [ ] ฝั่งที่เชื่อถือได้คำนวณยอดสินค้า ค่าจัดส่ง 30 บาทต่อคำสั่งซื้อ และยอดรวมใหม่; ค่าในหน้าเว็บไม่สามารถเปลี่ยนยอดที่บันทึกได้
- [ ] ที่อยู่และช่องทางติดต่อครบตามข้อมูลที่ใช้จัดส่ง; ข้อมูลไม่ครบแสดงข้อผิดพลาดโดยไม่สร้าง Order
- [ ] สินค้าหมดสต็อกหรือราคาเปลี่ยนแสดงผลให้ผู้ซื้อตรวจทานใหม่ก่อนยืนยัน
- [ ] การกดซ้ำหรือเครือข่ายขาดช่วงไม่สร้าง Order หลายใบจากการยืนยันครั้งเดียว
