# 07: ยืนยันผลชำระเงินและอัปเดต Order

**What to build:** ผู้ซื้อและผู้ดูแลระบบเห็นสถานะการจ่ายเงินทดสอบที่ตรงกับผลจาก Omise หลังยืนยันข้อมูลจากฝั่งเซิร์ฟเวอร์ รวมทั้งผลสำเร็จ ล้มเหลว และรอดำเนินการ

**Blocked by:** #06 เริ่มชำระเงินผ่าน Omise Test Mode.

**Status:** ready-for-agent

- [ ] ระบบรับเหตุการณ์การจ่ายเงินและตรวจผลจาก Omise ก่อนเปลี่ยนสถานะ Order; การกลับจากหน้าจ่ายเงินอย่างเดียวไม่ถือว่าสำเร็จ
- [ ] ผลสำเร็จ ล้มเหลว รอชำระ และหมดอายุแสดงตรงกันในหน้าผู้ซื้อ ประวัติบัญชี และหลังบ้าน
- [ ] เหตุการณ์ซ้ำหรือมาผิดลำดับไม่ทำให้ยอดหรือสถานะย้อนกลับผิด และไม่ทำให้ Order สำเร็จซ้ำ
- [ ] ผู้ใช้แก้สถานะชำระเงินเองผ่านหน้าเว็บหรือฐานข้อมูลโดยตรงไม่ได้
- [ ] ทดสอบผลสำเร็จและล้มเหลวด้วย Omise Test Mode โดยไม่ตัดเงินจริง
