# 03: ลูกค้าเห็นประวัติคำสั่งซื้อของตน

**What to build:** ลูกค้าที่เข้าสู่ระบบทำ Order ผ่าน checkout และเปิดประวัติกับรายละเอียดคำสั่งซื้อของบัญชีตนได้ โดยยังใช้สถานะการจ่ายเงินจริงของ Order

**Blocked by:** #01 Guest บันทึกคำสั่งซื้อรอชำระในระบบทดสอบ.

**Status:** ready-for-agent

- [ ] Order ที่สร้างขณะเข้าสู่ระบบผูกกับ UID ของลูกค้าและแสดงในหน้าประวัติของบัญชีนั้น
- [ ] รายการและรายละเอียดแสดงเลขคำสั่งซื้อ เวลา สินค้า ยอด และสถานะที่บันทึกจริง โดยไม่ใช้ข้อมูลตัวอย่าง
- [ ] ลูกค้าอีกบัญชีหนึ่งอ่าน Order นี้ไม่ได้ทั้งผ่านหน้าเว็บและการเรียกฐานข้อมูลโดยตรง
- [ ] การโหลดใหม่หรือกลับเข้าบัญชีเดิมยังเห็น Order ที่บันทึกไว้
- [ ] Order ที่ guest สร้างก่อนสมัครบัญชีไม่ปรากฏในบัญชีเพียงเพราะอีเมลตรงกัน
