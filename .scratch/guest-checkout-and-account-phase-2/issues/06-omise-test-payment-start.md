# 06: เริ่มชำระเงินผ่าน Omise Test Mode

**What to build:** ผู้ซื้อเลือกวิธีจ่ายเงินรุ่นแรกและเริ่มรายการชำระเงินทดสอบจาก Order ที่รอชำระ โดยเห็นสถานะรอหรือขั้นตอนยืนยันตามผลที่ Omise ส่งกลับ

**Blocked by:** #01 Guest บันทึกคำสั่งซื้อรอชำระในระบบทดสอบ.

**Status:** needs-info

**Needs info:** บัญชี Omise Test Mode และ test secret key; ต้องขอเปิดใช้ PromptPay กับ Omise และตั้งปลายทางรับผลการชำระเงิน

- [ ] การเริ่มชำระเงินใช้ยอดที่ฝั่งที่เชื่อถือได้อ่านจาก Order ไม่รับยอดที่หน้าเว็บแก้เอง
- [ ] สร้าง PromptPay charge จากฝั่ง backend ด้วยยอดของ Order และเก็บ QR reference; secret key ไม่ปรากฏในหน้าเว็บหรือ Git
- [ ] Order บันทึกรหัสอ้างอิงการจ่ายเงินทดสอบและแสดงสถานะรอเมื่อยังไม่ทราบผลสุดท้าย
- [ ] การเริ่มรายการซ้ำไม่สร้าง charge ซ้ำโดยไม่ตั้งใจ และข้อผิดพลาดไม่แสดงว่าชำระสำเร็จ
- [ ] เมื่อไม่มีการตั้งค่า Omise หน้าเว็บแจ้งว่าชำระผ่านเว็บไม่ได้และไม่เปิดขั้นตอนชำระเงินที่ใช้ไม่ได้
