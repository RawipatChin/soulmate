# 01: Guest บันทึกคำสั่งซื้อรอชำระในระบบทดสอบ

**What to build:** ผู้มาเยือนเลือกสินค้าที่ซื้อได้หนึ่งรายการ กรอกอีเมลติดต่อและที่อยู่ แล้วสร้าง Order สถานะ `pending_payment` ในสภาพแวดล้อมทดสอบได้โดยไม่ต้องสมัครบัญชี ระบบแสดงเลขคำสั่งซื้อหลังบันทึกจริงและให้ตัวตนชั่วคราวของผู้ซื้ออ่านคำสั่งซื้อของตนได้

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] ผู้มาเยือนเริ่มตัวตนชั่วคราวโดยไม่เห็นฟอร์มล็อกอิน และยังคงตะกร้าระหว่างเข้าสู่ checkout
- [ ] ฝั่งที่เชื่อถือได้ตรวจสินค้า ราคา จำนวน และสต็อกจากข้อมูลร้านก่อนบันทึก Order; ไม่เชื่อยอดรวม สถานะ หรือ role ที่หน้าเว็บส่งมา
- [ ] Order เก็บอีเมลติดต่อ ที่อยู่ รายการ ราคา ณ เวลาสั่ง ค่าจัดส่งทดลอง 30 บาทต่อคำสั่งซื้อ สถานะ และเลขคำสั่งซื้อ พร้อมระบุเจ้าของที่เป็น guest
- [ ] การกดยืนยันซ้ำหรือส่งคำขอซ้ำไม่สร้าง Order ซ้ำ และความล้มเหลวไม่แสดงว่าสั่งซื้อสำเร็จ
- [ ] กฎสิทธิ์ให้ guest อ่านเฉพาะ Order ของตน; การอ่าน Order ของผู้อื่นและการแก้ยอดหรือสถานะจาก client ถูกปฏิเสธใน Firebase Emulator
- [ ] ก่อนเชื่อมการจ่ายเงิน หน้าเว็บสำหรับผู้ใช้จริงไม่เปิดให้ยืนยันคำสั่งซื้อที่ยังชำระไม่ได้; เส้นทางสาธิตแสดง `pending_payment` ไม่ใช่ชำระสำเร็จ
